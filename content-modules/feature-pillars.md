# ReturnCopy — Feature pillars

## Core engine
- Return/refund policy and customer-facing reply drafts
- Clear, trust-preserving language for e-commerce
- Deterministic policy checks alongside the model

## Workflow & output
- Merchants and CX leads
- Draft → review jurisdiction rules → publish
- Decision-support — not legal advice

## Trust & control
- No compliance guarantee claims
- Local consumer law still wins
- Demo mode without a live API key
